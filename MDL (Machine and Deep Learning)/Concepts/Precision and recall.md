# Precision and recall

Recall (sensitivity): fraction of the target class that is found. Precision: fraction of objects assigned to the class that belong to it. Specificity: performance on the non-target class.

$$\text{recall}=\frac{TP}{TP+FN}\quad\text{precision}=\frac{TP}{TP+FP}\quad\text{specificity}=\frac{TN}{TN+FP}$$
