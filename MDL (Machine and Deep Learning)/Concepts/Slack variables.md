# Slack variables

Variables $\xi_i\ge0$ that let objects violate the margin. The parameter $C$ weighs violations against margin width.

$$\min\tfrac12\lVert w\rVert^2+C\sum_i\xi_i\ \text{ s.t. }\ y_i(w^Tx_i+b)\ge1-\xi_i$$
